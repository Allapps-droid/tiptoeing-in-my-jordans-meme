# Tiptoeing in My Jordans Meme

[Tip toeing in My Jordans Meme](https://tiptoeinginmyjordans.video/)

A photo-to-video meme generator for the familiar straw-barn tiptoe and dance. Put a new face in the scene while keeping its choreography, reactions, and original beat.

The same scene is also known as the **Rumpelstiltskin meme**.

[umpelstiltskin Meme Generator: Make the AI Tip-Toe Video](https://tiptoeinginmyjordans.video/rumpelstiltskin-meme)

Explore the character-focused page for sample casts, caption ideas, and a photo-role guide.

## What you can make

- Replace the foreground dancer with the person in your first photo.
- Optionally use a second photo for the person seated in the straw.
- Create the complete 12-second scene in landscape **16:9** or portrait **9:16**.
- Download a watermark-free **MP4** with the original beat.

## How to use the generator

1. Open the website using the link above.
2. Add a clear photo for the dancer, then an optional second photo for the seated person.
3. Choose the frame and a one-time video pack.
4. Start generation and return to **My Videos** for the finished result.

No video-editing experience or custom prompt is needed. Video packs are one-time purchases with no subscription.
